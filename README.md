# Capibara Royale Final - Wii U

## Texturas Ultra Detalladas
- Piso 1024x1024 con 12000 manchas + 500 flores + 400 tierra + rio + 8 caminos
- 90 arboles, 6 casas norte, 5 sur, 4 contenedores, 8 cofres dorados, rio, puente, nubes

## Como compilar con puntico verde desde el celular

1. Crea repo en GitHub llamado CapibaraRoyale
2. Sube TODO este ZIP (Add file -> Upload files)
3. Ve a Actions -> Build Wii U .wuhb - Capibara Royale Final
4. Dale Run workflow -> Run workflow
5. Espera 1-2 minutos -> Puntico verde ✅
6. Entra al workflow -> Abajo en Artifacts -> CapibaraRoyale-Final-wuhb-Puntico-Verde
7. Descarga el ZIP -> Adentro esta CapibaraRoyale.wuhb + index.html + icon.png + meta.xml
8. Copia todo a sd:/wiiu/apps/CapibaraRoyale/

## Controles
- Stick: Mover
- B: Rodar adelante 5m (esquivar balas)
- ZR: Disparar
- X: Recargar caminando 70%
- A: Agarrar cofres

## Juego que abre
El archivo wiiu/apps/CapibaraRoyale/index.html es el juego que si abre en celular y Wii U browser.
933KB con todo incluido.
